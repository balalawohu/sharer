# 项目安排

## step1

注册、登录的实现，需要注册账号。

注册账号可以使用手机号或者邮箱。但是同一个手机或者邮箱，只能对应一个账号。

用户名唯一。

```
account：手机号或邮箱，唯一，不可重复
username：注册时无需使用，但是可以修改。这个在注册的时候随机生成或者是用户_id。id是十位数。
password：密码
```

登录的时候主要也是这几个信息，account和password。用户名不可用于登录



## step2

上传功能实现。

登录之后，用户是可以上传自己的表情包的。所以说上传组件需要做好。





## step3

上传功能完毕之后，就可以开始做搜索和查看的功能。

搜索就是在首页的导航是可以搜索的，进入搜索页面之后，里面也有搜索框进行搜索，功能是一致的。

查看就是点击表情包卡片，可以进行查看，然后还可以进行下载。
